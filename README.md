


# 🚀 Task Manager App

Flask ve React kullanılarak geliştirilmiş modern bir görev yönetim uygulaması.

## ✨ Özellikler

* Kullanıcı kayıt ve giriş sistemi
* JWT tabanlı kimlik doğrulama
* Görev ekleme ve silme
* Kullanıcıya özel görev listesi
* Admin rolü ve yetkilendirme
* Modern ve responsive arayüz

## 🛠️ Teknolojiler

**Frontend**

* React
* JavaScript

**Backend**

* Flask
* SQLite
* PyJWT
* Flask-CORS

## ⚙️ Kurulum

### Backend

```bash
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
npm install
npm start
```

## 🎯 Amaç

Bu proje, Flask ve React kullanılarak JWT tabanlı kimlik doğrulama, görev yönetimi ve rol bazlı yetkilendirme konularında pratik yapmak amacıyla geliştirilmiştir.
